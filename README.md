# Verte Arquitetura e Construção

Site institucional responsivo em português, construído em HTML, CSS e JavaScript.

Os arquivos publicáveis estão em `dist/`. Pode ser servido por qualquer hospedagem estática. Para visualização local: `python -m http.server 8000 --directory dist`.

A marca original está em `dist/assets/marca-original.svg`. O símbolo usado na navegação mantém a geometria da marca, com enquadramento ajustado. As imagens são referências de arquitetura, identificadas no site, e não integram o portfólio da empresa.
